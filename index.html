Tecnologia para Abrir Portas no Mercado de Trabalho

O Currículo Fácil é uma aplicação desenvolvida como Projeto de Extensão Universitária pelos estudantes dos cursos de Ciência da Computação e Engenharia de Produção da UNIP - Campus Limeira.

Nosso objetivo é remover barreiras tecnológicas para que qualquer pessoa consiga criar seu currículo no padrão ATS e enviar diretamente pelo WhatsApp.

🛠️ Como Funciona a Estrutura

• Single-Page (SPA): Tudo é executado dentro deste mesmo arquivo index.html.
• Armazenamento: Os dados são salvos automaticamente neste navegador, no próprio dispositivo.
• Geração PDF: A prévia é convertida em um arquivo A4 para download. O envio por e-mail ou WhatsApp é iniciado no aplicativo escolhido por você.
